This plugin changes the photo sort order to 3 simple options:

- Default
- Oldest First
- Newest First

Sort is based on the creation date of photos.

'rightClick' plugin deactivates the context menu on websized pictures and more.
The Picture page, 'akBookStyle', 'Lightbox' and 'HD Shadowbox' are protected by default.
